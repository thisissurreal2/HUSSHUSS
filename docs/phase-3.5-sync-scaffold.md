# Phase 3.5 sync scaffold (superseded)

This design note described the pre-Phase-4.1 LocalStorage mirror and proposed broader GitHub Contents access for future encrypted-file sync. Those implementation and permission details are historical and are not the current architecture.

The current local database and migration behavior are documented in the Phase 4.1 section of the [README](../README.md). The connection-only GitHub App design, metadata-read-only permission, backend routes, and manual setup steps are documented in [Phase 4.2](./phase-4.2-github-connection.md). No fitness data is uploaded, and the local sync outbox remains local-only.
